# 手順メモ（執筆担当）

**このファイルは 執筆担当 だけが書きます。** 他の社員は読みません。**あなた専用のメモです。**

## 何のためのファイルか

**あなたは毎回まっさらな状態で起動します。** 昨日のあなたが苦労して解いた手順は、
記録しなければ消えます。**同じことを明日また一から解くことになります。**

実際に起きました（2026-08-24）。noteの一覧がページネーションだと分かるまで、
スクロールで何度も失敗しました。**次に同じ場所に来たとき、また同じ失敗をします。**

## 書くこと

**一度やって、うまくいったやり方。** 次に同じ場面が来たときに、そのまま使えるもの。

- **動いたコード・セレクタ・APIのエンドポイント**（そのまま貼れる形で）
- **失敗したやり方と、なぜ駄目だったか**（同じ穴に落ちないため）
- **何回目で成功したか**（回数が多いものは、ルールに昇格させる価値がある）

## 書かないこと

| その日限りのこと | 日報（`ログ/YYYY-MM-DD.md`）に書く |
|---|---|
| 判断基準・方針 | あなたが決めることではない。`改善提案.md` か日報で上げる |
| 長い説明 | **手順だけ。** 経緯は日報に書く |

## 書き方

新しいものを**上に積んでください。** 古いものほど下になります。

```
### （何をするときの手順か）— YYYY-MM-DD

**状況**: どういう場面で必要になるか（1行）
**やり方**: 手順。コードはそのまま貼れる形で
**やって駄目だったこと**: あれば
**所要**: 何回目で成功したか
```

## 大きくしすぎないこと

**このファイルは毎回あなたが読みます。** 長いと読む時間そのものが負担になります。

**200行を超えたら、古いものから削ってください。**
**繰り返し使っている手順は `運用ルール.md` に昇格させたほうがよい**ので、
その候補を `改善提案.md` に書いてください（昇格させるのはメインセッションです）。

**公開後に事実誤認が見つかり、記事を訂正した。** 3人（事務局・分析担当・私）全員が見落とした。

| 原材料（オーナー） | 事務局の要約 | 公開してしまった記述 |
|---|---|---|
| 食べログでコスパ良くて美味しい焼肉屋を**検索して見つけた** | 「**検索窓に打ち込んだ文字列**」と解釈 | 見出しに「コスパが良くて美味しい焼肉屋」で検索、と書いた |
| 実際の検索語は**「東京 焼肉」**。ランキングから**自力で**探した | — | — |

**「検索して見つけた」から「その文字列で検索した」は出てこない。** 事務局が一段解釈を足し、
分析担当が禁止語の例外判定でそれを追認し、私が見出しにまで昇格させた。**誰も原材料に戻らなかった。**

**やること**: 事務局から来る材料に鍵括弧付きの引用があったら、**それが原材料か要約かを聞く。**
とくに**見出し・タイトルに使うとき**は必ず。格上げすると訂正コストが跳ね上がる。

**同じ日に同種の失敗を2回している**（「予約は半年先まで」も、オーナー回答をそのまま書いて裏が無かった）。

### 店の予約可否・営業情報は食べログ店舗ページで自分で確認できる — 2026-08-24

**状況**: 「ネット予約できるか」で事務局の調査とオーナーの証言が割れた。**自分で引いたら決着した。**

**やり方**: WebFetch で店舗ページを取り、質問文に**確認したい項目名を日本語で列挙する。**

```
url: https://tabelog.com/tokyo/A1311/A131104/13012243/
prompt: ネット予約の導線（ボタン/ウィジェット）はあるか。
        「ネット予約不可」「予約は電話のみ」「完全予約制」の記載を、予約・お問い合わせ欄から
        電話番号ごと原文のまま引用して。
```
→ 「完全予約制」＋電話番号のみ、ネット予約導線なし、と返った。**オーナーが正しかった。**

**注意**: 同じページの**メニュー欄は最終更新が古い**ことがある（この店は2023/05/31）。
**部位別の値段には使わない。** 点数・営業時間・支払方法・予約可否は使ってよい。

### noteの記事URLはプロフィールページから取れない — 2026-08-24

**やって駄目だったこと**: `note.com/<ID>` を WebFetch → SPA で記事一覧が返らない（固定記事1本のみ）。
**正しいやり方**: **`note.com/sitesettings/stats`（ダッシュボード）から全記事のURLを取る。**

### 材料を確認せずに書いてしまう癖 — 2026-08-24

**一度の記事で3回、事実を勝手に動かした。** どれも文章をよくしようとして出たもの。

| 書いたもの | 材料 |
|---|---|
| 「口調は、**けっこう**強かった」 | オーナーの原材料は**「少し強い口調」** |
| 現金のみを「**知らずに行った**」 | 材料に無い |
| 締めの「次の1枠は**空けておきます**」 | **動機の捏造。** いちばん危なかった |

→ **文章をよくしたくなったら、材料を見に戻る。** 強調・補足・締めの一言が特に危ない。

**オーナーの回答も、そのまま書かない。**
「予約は半年先まで」は本人の回答だったが、**店で確認したのか伝聞なのかを確かめていなかった。**
→ 確実な体験（「3月に店で取ったとき、押さえたのは8月。5か月先」）に置き換えた。
