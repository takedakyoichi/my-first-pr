### 昇格候補① 公開済みnoteの「見出し」を差し替える

const r=document.createRange(); r.setStart(tn,A); r.setEnd(tn,B);   // 文字オフセット
const s=getSelection(); s.removeAllRanges(); s.addRange(r);
