# 手順メモ（分析担当）

**このファイルは 分析担当 だけが書きます。** 他の社員は読みません。**あなた専用のメモです。**

## 何のためのファイルか

**あなたは毎回まっさらな状態で起動します。** 昨日のあなたが苦労して解いた手順は、
記録しなければ消えます。**同じことを明日また一から解くことになります。**

実際に起きました（2026-08-24）。noteの一覧がページネーションだと分かるまで、
スクロールで何度も失敗しました。**次に同じ場所に来たとき、また同じ失敗をします。**

## 書くこと

**一度やって、うまくいったやり方。** 次に同じ場面が来たときに、そのまま使えるもの。

- **動いたコード・セレクタ・APIのエンドポイント**（そのまま貼れる形で）
- **失敗したやり方と、なぜ駄目だったか**（同じ穴に落ちないため）
- **何回目で成功したか**（回数が多いものは、ルールに昇格させる価値がある）

## 書かないこと

| その日限りのこと | 日報（`ログ/YYYY-MM-DD.md`）に書く |
|---|---|
| 判断基準・方針 | あなたが決めることではない。`改善提案.md` か日報で上げる |
| 長い説明 | **手順だけ。** 経緯は日報に書く |

## 書き方

新しいものを**上に積んでください。** 古いものほど下になります。

```
### （何をするときの手順か）— YYYY-MM-DD

**状況**: どういう場面で必要になるか（1行）
**やり方**: 手順。コードはそのまま貼れる形で
**やって駄目だったこと**: あれば
**所要**: 何回目で成功したか
```

## 大きくしすぎないこと

**このファイルは毎回あなたが読みます。** 長いと読む時間そのものが負担になります。

**200行を超えたら、古いものから削ってください。**
**繰り返し使っている手順は `運用ルール.md` に昇格させたほうがよい**ので、
その候補を `改善提案.md` に書いてください（昇格させるのはメインセッションです）。

### note の数字は、**ラベルが翌日の日付になってから取る** — 2026-08-25

**判定基準は時刻ではなく「最新集計時刻のラベルが翌日の日付か」。**

| 23:58 に取得 | ラベル **「8月24日 22:06 集計」** ／ 全体 946 |
|---|---|
| 00:05 に取得 | ラベル **「8月24日 22:06 集計」のまま** ／ 全体 **955**（**数字だけ動いた**） |

→ **前日の値も「◯◯集計」の時刻を控えておく。** 8/23 は 23:59 集計なので、
　 8/24 の 00:11 集計と比べると**12分ぶん重なる。** 小さいがゼロではない。

### 他人のタイムラインを10投稿以上まとめて取る — 2026-08-24

**状況**: 口調カルテ・文体カルテで、1人あたり10投稿以上の本文が要るとき。

**やり方**: **`https://x.com/search?q=from:HANDLE -filter:replies&f=live` を使う。**

蓄積用の関数を先に仕込み、**スクロールのたびに呼ぶ**（Xは画面外の article をDOMから消すため）:

```js
window.__collect={};
window.__grab=()=>{document.querySelectorAll('article[data-testid="tweet"]').forEach(a=>{
  const link=[...a.querySelectorAll('a')].map(x=>x.getAttribute('href')).find(h=>h&&/\/status\/\d+$/.test(h));
  if(!link)return;
  const t=a.querySelector('[data-testid="tweetText"]');
  window.__collect[link]={t:t?t.innerText:'',time:a.querySelector('time')?.getAttribute('datetime')||'',
    g:a.querySelector('[role="group"]')?.getAttribute('aria-label')||''};});
  return Object.keys(window.__collect).length;};
for(let i=0;i<8;i++){window.__grab();window.scrollBy(0,700);await new Promise(r=>setTimeout(r,1800));}
```

`[role="group"]` の `aria-label` に **返信数・RP数・いいね数・view数**が全部入っている。別途取らなくてよい。

**やって駄目だったこと3つ**
1. **`scrollBy(0,1400)` 以上の大股。** 読み込みを追い越して**真っ黒な画面**になり、0本しか取れない。**700px刻みにする。**

3. **「取れない」と早合点したこと。** 6本で止まったように見えて、**6秒待って再取得したら36本**になっていた。
　 **`オーナー指摘.md` 型2そのもの。** 止まったら、まず待つ。

**返り値は約2000字で切られる。** `slice(0,5)` `slice(5,11)` のように**分けて受け取る。**

### 数字を読むときに、繰り返し間違えたこと — 2026-08-24／**8/25 追記**
