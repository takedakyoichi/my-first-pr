# ⑦ 人間らしさの下限（2026-09-29 オーナー指摘「まだAI感のある口調」を受けて追加・**⑥のあと、送信直前に通す**）

## なぜ足したか（実測・9/25〜9/28 に送った15本 対 9/7 の他人88本）

| | 他人88本 | **うち15本** |
|---|---|---|

| 反応語・記号がある（！ … 笑 最高 めっちゃ 本当に 〜すぎ 等） | 43% | **0%** |

| ちょうど「1行＋空行＋1行」の2ブロック | 13% | **53%** |

（計測スクリプトは同じ物差しで両方を数えた。他人88本は `データ/2026-09-07-AI感分析-生データ.py`）

**⭐ 1本ずつなら問題が見えない。並べると全部同じ顔をしている。** 事実を丁寧な文で2つ置き、「。」で閉じ、気持ちは書かない。
**＝報告書の口調。** 外部の指摘「整いすぎ」「句読点が必ずある」「人間らしい温度感がない」と一致する。

## 原因（4つ）

1. **検査が全部「削る」向きだった。** ①〜⑥は余計なものを消す検査で、**人の声を足す項目は ⑥-4 の1つだけ**。その ⑥-4 も通らず（話し言葉 1/15）。
2. **9/7 の直しが行き過ぎた。** 当時は感情語が多すぎた（うち60%・他人11%）ので ⑥-3 で締めから外した。**結果、感情は締めからではなく本文から消えて 0% になった。** ⑥-6 の止め金は文の長さしか守っていなかった。
3. **手本が自分だった。** 他人の口調カルテ（20代男性）は3週以上作れておらず、ブリーフの口調カルテは「**うちの送信済みの実測**」。**AIの書いた文を手本にAIが書くので、同じ顔が再生産される。**
4. **完成文の出どころが材料台帳の「事実の行」。** 事実をそのまま文にすると説明文になる。**作り話を避ける仕組みが、同時に声も消していた。**

## 通し方（5項目。**ポストは全部・リプは下の ⑦-R と ⑦-4**）

### ⑦-1 全行を「。」で閉じない

**最後の行は「。」を付けない**（体言止め・「〜してる」止め・言いさし）。途中の行も、改行で区切れているなら「。」は要らない。
他人は「最後が。」38%。**⛔ 付けてよいのは5本に2本まで**（直近5本で数える）。

### ⑦-2 反応を1つ入れる（ただし作らない）

驚き・ツッコミ・本音・言いさし（「…」）・「笑」・誇張しない強調（「本当に」「めっちゃ」）のどれか1つ。
**⛔ 材料に無い感情は作らない。** 使えるのは ⓐ 材料台帳・note本文にオーナーが書いた気持ち（「いちばんおいしかった」「麺と戦ってる感じ」「正直あまり格好よくない」）、ⓑ 事実への短い反応で評価を足さないもの（「結局」「気づいたら」「いまだに」「〜のまま」）。
**⛔ ⑥-3（締めを評価語にしない）は変えない。反応は文の頭か真ん中に置く。**

### ⑦-3 話し言葉を1つ以上（⑥-4 を具体化）

使う形: **〜てる／〜けど／〜んだけど／〜だった／〜かも／〜じゃん／〜だよ／〜わ／ら抜き（起きれる）／助詞を落とす（「鍋もフライパンも油でぎとぎと」）**。
**⛔ 「〜ている」「〜ています」は、〜てる／〜てます に開く**（note誘導の敬体も同じ）。

### ⑦-4 「〜ので、」「〜から、」を1本に1回まで・直近5本で2本まで

理由を言わないと通じない時だけ使う。**並べるだけで通じるなら並べる**（「フチなしの平らな板。焼いたらそのまま上で包丁使える」）。

### ⑦-5 形をそろえない（**アカウント単位で見る・直近5本**）

- **「1行＋空行＋1行」は5本に2本まで。** 残りは 1行だけ／2〜3行を空行なしで続ける／3ブロック（⑥-5 の2つまでを超えない形で）
- **note誘導の締めの定型「〇〇の話を、noteに書いています。」は2本続けない。** 「noteに書いた↓」「詳しくはnoteに」「写真はnoteに載せてる」などに回す
- 文頭「正直、」は週1回まで（外部指摘のAI定番の書き出し）

## ⛔ ⑦の止め金（**過剰に崩さない**）

- **若者言葉を盛らない**（「ガチで」「エグい」「優勝」「〜しか勝たん」）。外部指摘で**AIが崩そうとした時の典型**。オーナーが言わない語は使わない（口調カルテ「借りない」）
- **絵文字・禁止語・リプの敬体固定は変えない**
- **1本に全部入れない。** ⑦-1〜⑦-3 は各1つ満たせば合格。崩しすぎも同じ顔になる
