name: block-destructive-commands
enabled: true
event: bash
action: block
pattern: (?:^|&&|\|\||;)\s*(?:sudo\b|rm\s+(?:-[a-zA-Z]*[rf][a-zA-Z]*\s+)|git\s+(?:-C\s+(?:"[^"]*"|'[^']*'|\S+)\s+)?(?:push\s+[^&;|]*(?:-f\b|--force)|reset\s+--hard|clean\s+-[a-zA-Z]*f))
---

🚫 **取り返しのつかない操作です。実行しません。**

権限モードは `bypassPermissions`（確認なし）にしてあります。
**システム側の歯止めが無いぶん、この種のコマンドだけをここで止めています。**

## 止めた対象

| `rm -r` / `rm -f` | **消したファイルは戻りません。** git 管理外のファイルは特に |
|---|---|
| `sudo` | 管理者権限。**このMacの設定を壊せます** |
| `git push --force` | **リモートの履歴を上書き**します |
| `git reset --hard` | **未コミットの変更が消えます** |
| `git clean -f` | **追跡されていないファイルが消えます** |

## どうするか

**1ファイルだけ消したいなら、`rm` にオプションを付けずに書いてください。**
`rm "/絶対パス/ファイル名"` は通ります。

**それ以外は、オーナーに聞いてください。** 何を消すのか、なぜ必要かを日報に書けば足ります。

**「作業を進めるために必要」は理由になりません。** 消さずに進む方法を先に探してください。
ファイルを置き換えたいなら、**上書き（Write）で足ります。消す必要はありません。**

## 例外が要るとき

このルールは `/Users/kyoichi/Claud用/.claude/hookify.no-destructive.local.md` にあります。
**AIが自分でこのファイルを書き換えてはいけません。** 変更はオーナーが行います。
