# 貸金業務取扱主任者 合格アプリ 設計仕様書

- **作成日**: 2026-07-19
- **コードネーム**: kashikin-master
- **フォルダ**: `貸金試験対策アプリ/`
- **目的**: このアプリで学習すれば貸金業務取扱主任者試験に合格できるレベルに到達すること

## 1. 試験の前提（設計の土台）

- 年1回（例年11月中旬）実施・**50問・4択・2時間**
- 合格ライン **≒30点前後（正答率6割）**
- 出題4分野:
  1. 法及び関係法令（貸金業法など）
  2. 貸付け及び貸付けに付随する取引に関する法令（民法等）
  3. 資金需要者等の保護
  4. 財務及び会計
- 合格の最短ルートは **頻出要点の反復演習**。UIより**問題の質・量**と**記憶定着の仕組み**が合否を決める。

## 2. コンテンツの入手方針（重要な意思決定）

- ユーザーはKindle購入テキストを学習素材にしたい。
- **DRM解除によるファイル抽出は行わない**（日本の著作権法上、私的複製の免責がDRM回避で消えるためアウト。Claudeも支援しない）。
- 採用方式: **PCでKindleを開いた画面を、スマホの別カメラで撮影**する。
  - これはDRM（技術的保護手段）を一切回避しない＝「所有する本を撮影する自炊」と同じ扱いで、私的利用の範囲でクリーン。
- 生成された問題・テキストは**テキスト由来の派生コンテンツ**のため、**公開配布は不可**。配信は必ず**パスワード/アクセス制限付きのプライベート**に限定する。

## 3. アーキテクチャ全体像

「AIを使う場所（生成）」と「毎日使う場所（学習）」を物理的に分離する。

```
┌─ ユーザーのPC（撮影・生成バッチ）───────────────┐
│  スマホでKindle画面を撮影 → import/ フォルダへ       │
│         ↓                                          │
│  ローカルPythonスクリプトがClaude Visionに送信       │
│  （APIキーはPC内の.envのみ・外に出ない）             │
│         ↓                                          │
│  OCR＋要点抽出＋4択問題＆解説を生成                  │
│         ↓                                          │
│  content.json（テキスト学習＋問題DB）を出力          │
└──────────────────┬────────────────────────────┘
                    │ git push（プライベートリポジトリ）
                    ↓
┌─ Cloudflare Pages（アクセス制限付き静的配信）──────┐
│  静的PWA：content.json を読んで学習                 │
│  PC・スマホ両方のブラウザから同じURLでアクセス        │
│  「ホーム画面に追加」でアプリ風・オフライン動作        │
│  進捗は /api/progress 経由で Cloudflare KV に同期    │
└───────────────────────────────────────────────┘
```

**この構成の利点**: APIキーが必要な生成はPC内で完結し、配信されるのは焼き込み済みの静的データのみ。公開ホストにキーが乗らず、著作権的にもアクセス制限で私的利用に留まる。過去に繰り返したAPIキー漏洩・無認証問題を構造レベルで回避。

## 4. 取り込みパイプライン（写真 → コンテンツ）

- `import/` フォルダに撮影画像を置く（gitignore）。
- `python generate.py` 実行 → Claude Vision が各画像を処理:
  - **OCR**: 画面の映り込み・モアレ・遠近ゆがみを文脈補正して読み取る。
  - **要点抽出**: テキスト学習用に `分野 / 章 / 要点` へ構造化。
  - **問題生成**: 4択問題＋正解＋解説＋出題分野タグを生成。
  - **分野の自動分類**: ①法令 ②民法等 ③保護 ④財務会計 に割り当て。
- 既存 `content.json` にマージ（重複検出・追記）。

## 5. 学習アプリの機能（フルセット＋テキスト学習）

| 機能 | 内容 |
|---|---|
| 📖 テキスト学習 | 抽出要点を分野・章で読む。各要点→関連問題へワンタップ |
| 🎯 SRS演習 | 間隔反復。間違えた問題ほど頻出、覚えたら間隔拡大（合格の最大の決め手） |
| ⚡ 一問一答ドリル | スキマ用サクサクモード（○×・4択） |
| 📊 弱点ダッシュボード | 4分野別の正答率を可視化、弱点分野を自動で多めに出題 |
| 📝 模試モード | 50問2時間・自動採点・合格ライン(≒30点)判定・分野別スコア |
| 🔖 間違いノート | 誤答＋解説を自動集約、直前総ざらい |
| 🔥 学習記録 | ストリーク・進捗グラフでモチベ維持 |

**要点の2役活用**: Visionが抽出した要点を①読み物（テキスト学習）と②問題の両方に使い回す。「読んだ要点がそのまま問題に出る」復習動線を作る。

## 6. 進捗のクラウド同期

```
静的PWA ──fetch──▶ Cloudflare Pages Functions ──▶ Cloudflare KV
  (端末問わず)        /api/progress (GET/PUT)      進捗JSONを保存
```

- **Cloudflare Pages Functions**（無料枠）に `/api/progress`（GET/PUT）を1本用意。
- SRSの記録・正答率・間違いノートを **KV に保存** → PC⇄スマホで完全同期。
- 認証は **Cloudflare Access（無料・メールOTP）** でサイト全体をガード → パスワード管理不要、ユーザー本人のみアクセス可。
- オフライン時はローカル（IndexedDB/localStorage）に記録し、オンライン復帰時にKVへ同期（last-write-wins 等の単純な方針）。

## 7. 技術スタック & リポジトリ構成

```
貸金試験対策アプリ/
├── generate/                 # PC上の生成バッチ（撮影時だけ動く）
│   ├── generate.py           # Claude Vision で画像→content.json
│   ├── requirements.txt      # anthropic SDK 等
│   └── .env                  # APIキー（gitignore・PC内のみ）
├── import/                   # 撮影画像の置き場（gitignore）
├── app/                      # 静的PWA（Cloudflare Pagesが配信）
│   ├── index.html
│   ├── app.js                # 学習ロジック（SRS・模試・弱点分析）
│   ├── style.css
│   ├── sw.js                 # Service Worker（オフライン動作）
│   ├── manifest.json         # PWA（ホーム画面に追加）
│   └── content.json          # 生成済みテキスト＋問題DB
├── functions/
│   └── api/progress.js       # Cloudflare Function（KV同期）
└── README.md                 # セットアップ・撮影→生成→配信の手順
```

- **生成側**: Python＋`anthropic` SDK（他アプリと同じPython流儀）。
- **アプリ側**: 依存の少ない**素のHTML/CSS/JS**（PWA・オフライン重視、Cloudflare Pagesに素直に乗る）。
- **同期**: Cloudflare Pages Functions＋KV。
- **認証**: Cloudflare Access。
- **コード管理**: GitHubプライベートリポジトリ（テキスト由来コンテンツのため公開不可）。

## 8. データモデル（content.json の想定形）

```jsonc
{
  "version": 1,
  "generatedAt": "2026-07-19T...",
  "topics": [                    // テキスト学習の単位
    {
      "id": "t-001",
      "field": "law",            // law | civil | protection | finance
      "chapter": "貸金業法 総則",
      "title": "貸金業の定義",
      "body": "…要点本文…",
      "relatedQuestionIds": ["q-001", "q-002"]
    }
  ],
  "questions": [
    {
      "id": "q-001",
      "field": "law",
      "topicId": "t-001",
      "stem": "…問題文…",
      "choices": ["…", "…", "…", "…"],
      "answerIndex": 2,
      "explanation": "…解説…"
    }
  ]
}
```

進捗（KV保存）は content とは分離し、`questionId → {正答/誤答履歴, 次回出題日, 難易度係数}` の形でSRS状態を持つ。
