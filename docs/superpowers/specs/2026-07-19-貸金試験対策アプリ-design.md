# 貸金業務取扱主任者 学習アプリ 設計仕様書

- **作成日**: 2026-07-19
- **コードネーム**: kashikin-master
- **フォルダ**: `貸金試験対策アプリ/`
- **目的**: 手持ちのKindle教材（スクショ）を繰り返し読んで学習し、貸金業務取扱主任者試験の合格を目指す

  代わりに **スクショ画像をそのまま読む「画像教材リーダー」＋学習補助**に方針転換。
  **AI・API・OCRを一切使わない＝完全無料・オフライン**。
  - 旧 Plan 1（`generate/` の Vision 生成パイプライン）は**削除**（ユーザー判断・2026-07-20）。将来必要になれば git 履歴から復元可能。
  - 本版が正。以降の設計は画像リーダーを指す。

## 1. 試験の前提（参考）

- 年1回（例年11月中旬）・**50問・4択・2時間**・合格ライン **≒30点前後（正答率6割）**
- 出題4分野: ①法及び関係法令 ②貸付け・取引に関する法令（民法等）③資金需要者等の保護 ④財務・会計
- 本アプリは「教材を繰り返し読み、要復習箇所を忘却曲線で潰す」読み込み型学習を支援する。

## 2. コンテンツの入手方針

- ユーザーはKindle教材の各ページを**スクリーンショット**で保持（環境が標準でキャプチャを許可＝保護手段の突破なし＝私的利用としてクリーン）。
- 画像から文字を抽出せず、**画像のまま表示して読む**（OCR不要＝文字化けゼロ、AIコストゼロ）。
- 画像は教材由来の著作物のため、**公開配布は不可**。配信は必ず**Access保護のプライベート**に限定。

## 3. アーキテクチャ全体像

AI・APIを使わない。画像を並べて表示し、学習の進捗だけを覚える静的PWA＋軽量サーバーレス同期。

```
┌─ ユーザーのPC ─────────────────────────────────┐
│  スクショ画像を app/pages/ に置く（ファイル名＝読む順） │
│  python build_manifest.py 実行                       │
│    → app/pages/ を走査し app/manifest.json を生成/更新  │
│    → 章の区切り・章名だけユーザーが軽く編集             │
│         ↓ git push（プライベートリポジトリ）           │
└──────────────────┬────────────────────────────────┘
                    ↓
┌─ Cloudflare Pages（Access保護・静的配信・無料）──────┐
│  静的PWA：manifest.json を読み、画像をページめくり表示   │
│  学習補助：既読/要復習・SRS復習・メモ・記録             │
│  進捗/メモ/復習予定 → /api/state 経由で Cloudflare KV   │
│  PC⇄スマホ同期・オフライン動作・ホーム画面に追加        │
└───────────────────────────────────────────────────┘
```

## 4. コンテンツ定義（manifest.json）

`build_manifest.py` が `app/pages/` の画像（.png/.jpg/.jpeg/.webp、ファイル名昇順）から生成。
既存 `manifest.json` があれば**ユーザーの章編集を保持**して差分追記（画像パスをキーにマージ）。

```jsonc
{
  "version": 1,
  "chapters": [
    {
      "id": "ch-1",
      "title": "第1章 貸金業法 総則",     // ユーザーが編集
      "pages": [
        { "id": "p-001", "image": "pages/001.png" },
        { "id": "p-002", "image": "pages/002.png" }
      ]
    }
  ]
}
```

- 初回生成時は全ページを1章（`title: "未分類"`）にまとめる。ユーザーは章を分割・命名するだけ。未編集（全1章）でも動作する。
- `page.id` は安定（画像パスから決定的に採番）。進捗データはこの id で紐づく。

## 5. 学習補助機能（全部入り）

| 機能 | 内容 |
|---|---|
| 📖 画像リーダー | 画像をページめくり表示。ピンチ/ボタンでズーム。前後ナビ |
| 📑 目次(TOC) | 章・ページ一覧から任意ページへジャンプ。現在地表示 |
| ✅ 既読/未読 | ページ閲覧で既読化。手動トグルも可 |
| 🔁 SRS復習 | 「要復習」ページを Leitner ボックス方式で再表示スケジュール |
| 📝 メモ | ページごとに自由メモ |
| 🔥 学習記録 | 連続学習日数(ストリーク)・既読進捗% |
| ☁️ 同期 | 進捗/メモ/復習予定を Cloudflare KV で PC⇄スマホ同期 |

### SRS（Leitner ボックス）仕様
- ページを「要復習」にすると復習対象に入る（box 0、翌日期限）。
- 復習時「覚えた」→ box を1上げ、間隔を延長。「まだ」→ box 0 に戻す。
- 間隔（日）: box 0..5 = `[1, 2, 4, 8, 16, 32]`。期限日 ≤ 今日 のページが「今日の復習」。

## 6. 進捗データモデル（localStorage / KV 共通）

```jsonc
{
  "pages": {
    "p-001": { "read": true, "box": 2, "due": "2026-07-25", "note": "3条の登録要件を確認" }
    // read: 既読か / box,due: SRS状態(要復習にした時のみ付与) / note: メモ
  },
  "activityDates": ["2026-07-19", "2026-07-20"]  // 学習アクションのあった日(ストリーク算出)
}
```

- 進捗は content（manifest/画像）と分離。KV には1ユーザー1レコードで保存。
- オフライン時は localStorage に保存し、オンライン復帰時に KV へ同期（last-write-wins）。

## 7. 技術スタック & リポジトリ構成

```
貸金試験対策アプリ/
├── build_manifest.py         # app/pages/ → manifest.json 生成/更新（Python・stdlibのみ）
├── tests/                    # build_manifest.py の pytest
├── import/ (旧) / app/pages/ # スクショ画像の置き場（実データは gitignore、配信時のみ private）
├── app/                      # 静的PWA
│   ├── index.html
│   ├── style.css
│   ├── js/
│   │   ├── srs.js            # Leitner スケジューリング（純粋関数・node:test）
│   │   ├── progress.js       # 既読/ストリーク/メモ/進捗%（純粋関数・node:test）
│   │   ├── store.js          # 永続化（localStorage / 後で KV）
│   │   ├── reader.js         # 画像表示・TOC・ナビ（DOM）
│   │   └── app.js            # 起動・配線
│   ├── js/tests/             # srs / progress の node:test
│   ├── sw.js                 # Service Worker（オフライン）
│   ├── manifest.webmanifest  # PWA（ホーム画面に追加）
│   └── manifest.json         # コンテンツ目次（build_manifest.py が生成）
├── functions/
│   └── api/state.js          # Cloudflare Function（KV 同期・Plan B）
└── README.md
```

- **リーダー本体**: 依存の少ない素の HTML/CSS/JS（ESMモジュール。ブラウザとnode両方でimport可）。
- **ロジック（srs/progress）**: DOM非依存の純粋関数に切り出し、`node --test` でユニットテスト。
- **manifest 生成**: Python 標準ライブラリのみ（追加依存なし）。pytest でテスト。
- **同期/認証/配信**: Cloudflare Pages Functions + KV + Access（Plan B）。
- **コード管理**: GitHubプライベートリポジトリ（画像は著作物のため公開不可）。

## 8. プラン分割

- **Plan A（本スペックの中核）**: 静的PWA 画像リーダー＋全学習補助。進捗は localStorage、1台で完全動作・オフライン。
- **Plan B**: Cloudflare KV 同期＋Access＋デプロイ（PC⇄スマホ）。
- **削除済み**: 旧 Plan 1（`generate/` の Vision 生成パイプライン）。git 履歴に残る。
