## 原文1: 挽肉と米（吉祥寺）

> 焼きたてハンバーグと炊き立ての米を同時提供。
> 　米は常に炊き立てを食べるためか少量です(おかわり自由)
> 　米にハンバーグをディップしてまず一口、中から大量の肉汁が溢れ出します。この時点で米は1杯消費
> 　あまりにも肉汁が溢れるものですから、ハンバーグに口つけてチューチュー吸ってみました。すると肉汁が一瞬で脳に届き私は覚醒しました。肉汁に含まれるニコチン(※そんなん無いです)でキマッテシマイマシタ
> 　僕の腹リミッターは外れ、からのお皿を見ると店員さんがお代わりを勧めてくるライスわんこそば。
> (店員さん呼ぶの恥ずかちい僕にはとっても助かるお節介)
> 　店出る時には腹はち切れ大爆発でした。。
> 　色々薬味があるのですが、正直ハンバーグのスペックが医者、外コン、伊藤忠商事勤務ぐらいあったので、もはや飾りですね(薬味も拘り抜かれてました。モテる男にブランドバックですね、、)
> 　デフォルト３個なんですけど、30個食べればLINE予約できるようになるらしく、次回はハンバーグ大食いチャレンジしに行こかな思ってます！(来店初回絶対ミスるので入り方は見てね！！)

## 原文2: チャイブレイク（吉祥寺）

> 喉で感じるアイスチャイ
> 紅茶にめちゃくちゃ拘ってるのが分かる店内だったのですが、僕はチャイに挑戦しました！チャイはインドカレーのお口直しで何回か飲んでるのですが、マンゴーラッシー派です。
>
> 出てきたチャイはなんか泡立ってて、ビールかなんかかなと思いました。流石に朝からは飲めないぞと思って一口、それはもう最高の喉越しでした。これすごいのが、唇と舌は泡に包まれて肝心のチャイ部分は喉にダイレクトアタックしてくるんですよ。ビビるぐらい最高の喉越し！その後に喉から鼻にくる香り
> 味ってこんな3Dやっけって思うぐらい立体を感じて、もうにやけが止まらない。東京って建物いっぱいあるけど味も建築されてるんかと思いもうメロメロ
> あとフレンチトーストもすごかった、、僕レベルのど素人でもわかったんですけど、あくまで主役は紅茶やチャイなんです。中まで味染みてて、トーストもめっちゃうまいんですけど、これはチャイ引き立てるための味やなって思いました。(言葉にすんの難しい、一回行って共感してください！)
>
> 近くに激うまハンバーグあるんですけど入り方特殊で、間の時間に行くのが超おすすめです！
> このデートプランはイケると非モテ2人で語ってました笑

## 文体の特徴（2本からの実測）

| 項目 | 実測 |
|---|---|
| 一人称 | 「僕」が基本。ボケの瞬間だけ「私」に切り替え（覚醒シーンの1回） |
| 文末 | 敬体（です・ます）がベース。言い切りの体言止めも混ざる（「この時点で米は1杯消費」） |
| 関西弁の量 | 文中に混ぜる方式で語尾全部は関西弁にしない。「行こかな思ってます」「〜やなって」「やっけ」「〜んかと」「すんの」など2本で約7箇所＝全体の1割程度 |
| 括弧 | 2本で8回。用法は3つ: ①注釈ツッコミ（※そんなん無いです）②自虐（恥ずかちい僕には…）③読者への指示（入り方は見てね！！） |
| 旨さの言い方 | **「美味しい」は2本で0回。** 身体感覚の実況で言う: 脳に届く・覚醒・腹リミッター・喉にダイレクトアタック・喉から鼻にくる香り。「うまい」は使う（激うま・めっちゃうまい） |
| ボケの型 | 誇張比喩がオチの主役: 肉汁ニコチン／ライスわんこそば／スペックが医者・外コン・伊藤忠／モテる男にブランドバック／味の建築 |
| カタカナ強調 | キマッテシマイマシタ（テンションのピークで1回だけ） |
| 実用情報 | 笑いに混ぜて運ぶ: おかわり自由・LINE予約の条件・入り方特殊・デートプラン。情報だけの行を作らない |
| キャラ | 自虐（非モテ・店員さん呼ぶの恥ずかしい・ど素人） |
| 締め | 読者への呼びかけ＋「！」（見てね！！／一回行って共感してください！／語ってました笑） |

## AI社員が書くときのルール

**借りてよいもの（形）**
- 構成: 実況 → ボケ → 実用情報 → 読者への呼びかけ
- 敬体ベース＋関西弁1割・括弧ツッコミの頻度・体言止めの混ぜ方
- 「美味しい」を使わず身体感覚で書く姿勢

**借りてはいけないもの（中身）**
- **誇張比喩・ボケの中身。** ニコチンもわんこそばも、オーナーが実際に食べた体験からしか生まれない。AIが比喩を自作した瞬間にエセになる
- 行っていない店の体験・感覚の捏造

**書けない部分の渡し方**
- ボケ・比喩が必要な箇所は自作せず **【オーナー追記: ここに一言】** と置いて渡す
- 事実（値段・予約条件・個数・営業情報）は投稿前に実測かレシート・公式で確認する。原文1の「30個でLINE予約」も投稿前に要確認
