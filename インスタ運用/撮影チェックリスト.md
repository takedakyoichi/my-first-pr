# 撮影チェックリスト

最終更新: 2026-08-30

撮影は「行った人」がやる。2人で品質を揃えるためのリスト。
**店を出る前に全部チェック。** 帰ってから「あれ撮ってない」が一番のロス。

---

## 撮るもの（この順で）

- [ ] 料理の寄り（湯気・ツヤが残ってるうちに最優先で撮る）
- [ ] 料理の引き（テーブル全体、量感がわかる画）
- [ ] 断面・持ち上げ（麺リフト、割った断面など動きのある1枚）
- [ ] メニュー表（値段が読める解像度で）
- [ ] 店内の雰囲気（他のお客さんの顔が入らない角度で）
- [ ] 外観・看板（店名がわかるもの。地図がわりになる）

## 撮り方

- 明るさ優先。窓際か照明の下の席に座る。暗い店はスマホのナイトモード
- 寄りは**斜め45度**か**真上**。中途半端な角度が一番まずそうに写る
- 1カット3枚ずつ撮っておく（ブレ保険）
- **表紙用に「料理を中央・上下に余白」の寄りを必ず1枚**（上下に文字を入れるため。実測8/8がこの構図）
- フラッシュは使わない（店にも他の客にも迷惑、色も死ぬ）

## 撮影と一緒にメモするもの（投稿の必須4点の材料）

- [ ] 払った金額（レシート写真でOK）
- [ ] 着いた時刻・**並んでいた人数・何分で入店したか**（曜日とセットで。例:「土曜12時・並び20人・25分で入店」。この粒度で書く人は23件中0＝うちの看板）
- [ ] 予約したか、できるか（店員さんに聞けたらベスト）
- [ ] 使った駅と改札からの体感時間

## マナー

- 撮影可か不安な店は一言聞く（「写真撮ってもいいですか」で断られたら潔く諦める）
- 撮影は席に着いてから。厨房・スタッフにカメラを向けない
- 混んでる時間の長居撮影はしない。撮影は5分以内、あとは普通に食べる
