# 投稿の型（カルーセル＋キャプション）

最終更新: 2026-08-30

毎回この型で作る。型を変えたくなったら月1の数字を見る会で2人で決める。

---

## カルーセル構成（8〜10枚）

| 枚数 | 中身 | ねらい |
|---|---|---|
| 1枚目 | 一番シズル感のある写真＋店名＋**エリア名（駅名）**＋関西弁ひと言キャッチ | 指を止めさせる。エリア名はベンチマーク実測で10件中8件が表紙に明記（2026-08-31追加） |
| 2〜6枚目 | 料理（寄り・引き・断面）、店内の雰囲気 | 行った気にさせる |
| 7枚目 | メニュー表の写真＋実際に頼んだもの | 値段の透明性 |
| 8枚目（ラスト） | 店舗情報まとめ＋「保存してな」 | 保存させる |

### ラスト1枚に必ず載せる（運用方針の必須4点）

- 払った金額（1人あたり）
- 待ち時間（◯曜◯時で◯分）
- 予約可否と方法
- 最寄駅から徒歩◯分
- 営業時間・定休日

## キャプションの型

```
【エリア】店名

関西弁のひと言感想（1〜2文。ここが一番キャラの出る場所）

▼ 頼んだもの
・◯◯ ◯◯円
・◯◯ ◯◯円

▼ 行く前に
待ち時間: ◯曜◯時で◯分
予約: 可（食べログ）／不可
場所: ◯◯駅から徒歩◯分

保存しといたら行くとき迷わんで🔖

#東京グルメ #◯◯グルメ（エリア） #ジャンル系タグ2〜3個
```

2人が実際に食べたときに言った言葉をそのまま使うのが正解。最初の10投稿分を2人で出し合って、ここに実例を貯めていく。

書き出しの方向性だけ決めておく:

| 方向 | 例の骨組み |
|---|---|
| 素直な感動 | 「〜、もうてもうた」「〜やん、これ」 |
| 名前の約束に乗せる | 「ここはハズさへん」「ハズしたことにしたい店、無かった」 |
| 上京あるある | 串カツ・粉もん・出汁の話題のときだけ。月1〜2回まで |

**金額の安い高いはネタにしない**（2026-08-31 オーナー決定・運用方針.md参照）。金額はデータ欄に事実として書くだけ。

### ハッシュタグ

- 大タグ（#東京グルメ）1個＋エリアタグ1個＋ジャンルタグ2〜3個。計5個以内
- 30個付けは古い。位置情報タグの方が効く

## ストーリーズ

- それ以外: 行った店の速報、アンケートスタンプ（「どっちの店見たい？」）で次のネタを決めるのもあり
