# 投稿の型（カルーセル＋キャプション）

最終更新: 2026-08-30

毎回この型で作る。型を変えたくなったら月1の数字を見る会で2人で決める。

## カルーセル構成（8〜10枚）

| 枚数 | 中身 | ねらい |
|---|---|---|
| 1枚目 | **表紙テンプレ（下記「表紙の型」に固定）** | 指を止めさせる |
| 2〜6枚目 | 料理（寄り・引き・断面）、店内の雰囲気 | 行った気にさせる |
| 7枚目 | メニュー表の写真＋実際に頼んだもの | 値段の透明性 |
| 8枚目（ラスト） | 店舗情報まとめ＋「保存してな」 | 保存させる |

### 表紙の型（2026-09-03 学習セッションで制定・以後固定）

**表紙は「1回きりのデザイン」ではなく「型の制定」**（実測: 8/8が全投稿で同一テンプレ）。
初投稿で作った表紙がそのまま金型になる。変えるときは月1の会で。

4点構成（えりログ型）:

| 位置 | 中身 |
|---|---|
| 上部 | 関西弁キャッチ（**1行15字以内**。2行に割るなら1行9〜11字） |
| 右上 | **縦書きの駅名**（白い座布団に黒文字。「吉祥寺」の粒度。都県名にしない） |
| 下部 | 店名＋**【メニュー名 ¥実額】**（表紙実額は8件中1件だけの空き地＝うちの看板） |
| 隅 | 小さくアカウントロゴ |

- 文字は**白1色＋薄い黒縁**。キャッチに座布団は敷かない（実測: 白1色7/8・キャッチ座布団0/8）
- 写真は料理の寄り。**文字は上下2〜3割に収め、中央の料理を空ける**（8/8）
- フォントは太めの明朝

実装値（2026-09-03 初投稿で制定・`ツール/表紙生成.py` で再現可能）:
1080×1350（4:5）／フォント=ヒラギノ明朝 ProN W6／キャッチ76px・y64・黒縁6px／
縦書き駅名=58px・白座布団（角丸14）・右端から36px・y210／店名46px・y1146／【メニュー ¥実額】62px・y1216

### ラスト1枚に必ず載せる（運用方針の必須4点）

- 払った金額（1人あたり）
- 待ち時間（◯曜◯時で◯分）
- 予約可否と方法
- 最寄駅から徒歩◯分
- 営業時間・定休日

## キャプションの型

```
関西弁のひと言フック（9〜15字目安・この1行だけで独立）

【エリア】店名

感想本文（口調カルテの文体で。ここが一番キャラの出る場所）

▼ 頼んだもの
🍚 ◯◯ ◯◯円

▼ 行く前に
⏰ 待ち時間: ◯曜◯時で◯分（並び◯人）
📱 予約: 可（方法）／不可
🚃 場所: ◯◯駅から徒歩◯分

保存しといたら行くとき迷わんで🔖

#◯◯グルメ #◯◯ランチ（エリア複合2〜3個） #ジャンルタグ1〜2個
```

**形のルール（2026-09-03 学習セッションで制定）:**

- **1行目は関西弁フック**。【エリア】店名は2行目へ（実測: フック開始14/14・1行独立＋空行9/9・疑問形は使わない0/12）
- **改行は文の切れ目でだけ。段落の間に空行**。note式の長段落のまま出さない（長段落は12本中0）。文の途中では折らない
- **感想文中の絵文字は0個**。絵文字を使うのはデータ欄の行頭アイコンと締めの🔖だけ（0個で9.6万の実例あり。中途半端に散らす型は存在しない）
- データ欄の行頭アイコンは毎回同じものを使う（行頭アイコンは実測4/4の全員一致）
- CTA「保存しといたら行くとき迷わんで🔖」は**毎回一言一句同じ**（効いているのは文言より定型性）

### 関西弁キャッチの温度感

**キャプションの口調は `口調カルテ.md` が正典（2026-08-31 オーナーの生文体2本を収録）。**
AIやテンプレで作ると一発でエセ関西弁になるので、書く前に必ず原文を読む。ボケ・比喩は自作せず【オーナー追記】で渡す。
実例はオーナーと友達が食べたときの言葉をここと口調カルテに貯めていく。

書き出しの方向性だけ決めておく:

| 方向 | 例の骨組み |
|---|---|
| 素直な感動 | 「〜、もうてもうた」「〜やん、これ」 |
| 名前の約束に乗せる | 「ここはハズさへん」「ハズしたことにしたい店、無かった」 |
| 上京あるある | 串カツ・粉もん・出汁の話題のときだけ。月1〜2回まで |

**金額の安い高いはネタにしない**（2026-08-31 オーナー決定・運用方針.md参照）。金額はデータ欄に事実として書くだけ。

### ハッシュタグ（2026-09-03 暫定変更）

- **大タグ（#東京グルメ）は外す**（実測: 使用1/14）。エリア複合2〜3個（#吉祥寺グルメ #吉祥寺ランチ）＋ジャンル複合1〜2個
- 最終形は投稿開始後、自分のインサイト（ハッシュタグ経由の到達）を見て月1の会で決める（未決#3）
- 30個付けは古い。位置情報タグの方が効く
